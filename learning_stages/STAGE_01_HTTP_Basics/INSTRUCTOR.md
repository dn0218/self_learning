## 关键知识点

### HTTP协议特点
- 无状态：每次请求独立，服务端不记住之前请求
- 请求-响应模式：客户端发起，服务端响应
- 基于TCP：需要先建立TCP连接

### 状态码分类
```
2xx - 成功（200 OK, 201 Created）
3xx - 重定向（301永久, 302临时）
4xx - 客户端错误（401未认证, 403无权限, 404不存在, 429限流）
5xx - 服务端错误（500代码异常, 502上游不可达, 503过载）
```

### 常用请求头
```
User-Agent: 客户端身份标识
Content-Type: 请求体格式
Authorization: 认证信息
Accept: 期望的响应格式
```

## 常见问题与解答

**Q: 为什么需要设置User-Agent？**
A: 很多API和网站会拒绝默认的Python requests User-Agent。在本项目中，智谱API的WAF会拦截默认User-Agent，必须自定义才能调用。

**Q: HTTP无状态意味着什么？**
A: 服务端不记住之前请求。每次请求都需要携带认证信息（Token/Cookie）。这是REST API设计的基础原则。

**Q: 429状态码怎么处理？**
A: 请求太频繁，应该等待一段时间后重试。生产环境用指数退避（1s, 2s, 4s...）。
